# Credits

These scripts are JavaScript ports of SandFly screen reader scripts. SandFly is a fork of Backtalk, but its scripts are written in Lua against a different script API, so they cannot be installed in Backtalk as they are. Each script here does everything the SandFly original does.

Original scripts and their authors:

- SandFly and its script authors (see each script file and the tables in the README for the name behind every port).
- Aaron Hewitt's scripts (from aaron-gh/sandfly-scripts) and their ports are under the Apache License 2.0.
- Other original repositories have no license; they were shared publicly by their authors to help others, and any author who wants their port taken down can open an issue.

Backtalk is trypsynth's screen reader for Android.

Questions and bug reports are welcome in the [SerrebiProjects Telegram group](https://t.me/SerrebiProjects). More serrebi projects: [projects.serrebiradio.com](https://projects.serrebiradio.com).
